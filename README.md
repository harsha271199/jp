# Construction Job Scraper V3
Targets U.S. construction/civil roles suitable for entry-level candidates and candidates with up to ~2 years of required experience.

V3 fixes the regex crash, improves Workday parsing, and actually attempts previously `auto` company rows through ATS discovery / static career-page crawling. Direct Greenhouse, Lever, Ashby and Workday sources are preferred.

High-priority construction sources pre-mapped in this release include Holder Construction, Kiewit, JE Dunn, Clark, DPR, Hensel Phelps, Mortenson, Suffolk, Turner, Fluor, McCarthy and Whiting-Turner.
